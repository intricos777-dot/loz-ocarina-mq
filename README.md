# The Legend of Zelda: Ocarina of Time - Master Quest
Remaster build with updated shaders and graphics based on the Twilight Elysium engine and the existing SoH Master Quest build.

## Features
- Updated shader pipeline from Twilight Elysium
- Cleaner graphics and lighting
- Master Quest dungeon layouts
- Modern resolution support
- Self-healing and debugging wrappers included

## Status
Scaffold only. No proprietary assets included.
